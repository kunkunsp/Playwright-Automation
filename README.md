# 🎭 Playwright Automation Project

Este es mi proyecto profesional de automatización de pruebas, migrado a **TypeScript** para mayor robustez y mantenibilidad.

## 🚀 Estado del Proyecto
- [x] Configuración de entorno en Pop!_OS.
- [x] Conexión exitosa con GitHub vía SSH.
- [x] Creación de Page Object Model (POM).
- [x] Implementación de TypeScript y Path Mapping (@pages).

## 🛠️ Tecnologías
* **SO:** Pop!_OS 🐧
* **Herramienta:** Playwright
* **Lenguaje:** TypeScript (TS) 🟦
* **Patrón de Diseño:** Page Object Model (POM)

## 📁 Estructura del Proyecto
* `Pages/`: Contiene los Page Objects y la lógica de negocio.
* `tests/`: Escenarios de prueba automatizados.
* `@pages/`: Alias configurado para importaciones limpias.
